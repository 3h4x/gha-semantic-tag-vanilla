# gha-semantic-tag-vanilla

Zero-dependency drop-in replacement for `semantic-release` in GitHub Actions: reads your
existing `.releaserc`, computes the next version from conventional commits, tags, publishes
and creates the GitHub Release — with no npm dependency tree.

Status: design phase. See [the design spec](docs/superpowers/specs/2026-10-12-gha-semantic-tag-vanilla-design.md).
